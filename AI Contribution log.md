# AI Contribution Log

## SLE-2: BFS vs DFS Performance Profiling

### AI Tool Used

* **ChatGPT**

### Purpose of Using AI

ChatGPT was used as a supporting learning tool throughout the SLE-2 experiment. It was mainly used to understand the concepts, implementation approach, profiling process, and interpretation of the experimental results.

### Areas Where AI Assisted

1. **Understanding BFS and DFS**

   * Explained the working principles of Breadth-First Search (BFS) and Depth-First Search (DFS).
   * Helped understand the differences between queue-based BFS traversal and stack/recursive DFS traversal.
   * Provided conceptual guidance about search order and node expansion.

2. **Python Program Development**

   * Assisted in understanding the structure of the Python implementation.
   * Helped with graph representation and traversal logic.
   * Provided guidance for implementing the node expansion counter.

3. **Performance Measurement**

   * Explained the use of Python's `timeit` module for measuring execution time.
   * Helped understand how repeated executions can be used to obtain average timing values.
   * Provided guidance on comparing execution time between BFS and DFS.

4. **Py-Spy Profiling**

   * Explained the purpose and basic usage of Py-Spy for Python performance profiling.
   * Helped understand how flamegraphs can be generated from profiling data.
   * Assisted in understanding how flamegraphs represent runtime activity.

5. **Nodes Expanded**

   * Helped explain how the number of expanded nodes can be recorded during search.
   * Assisted in understanding how node expansion can be used as an additional performance metric.

6. **Result Analysis**

   * Helped interpret the results obtained from the student's actual program execution.
   * Assisted in presenting the observations clearly in the SLE-2 report.
